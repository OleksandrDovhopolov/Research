# Unity Mobile LiveOps Prototype

A Unity mobile game prototype focused on scalable client architecture and LiveOps features.

## Features
- Card Collection
- Battle Pass
- Fortune Wheel
- Fishing mechanic
- Addressables-based asset loading
- Firebase Analytics integration
- Ads / IAP integration mock or implementation
- DI-based architecture

## Technical Focus
- Modular architecture
- OOP / SOLID / GRASP
- Async workflows with UniTask
- Addressables loading/unloading
- Mobile performance considerations
